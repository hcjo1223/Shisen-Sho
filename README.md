# 🍓 말랑 사천성 (Emoji Shisen-Sho)

과일·동물 이모지로 즐기는 힐링 사천성 퍼즐 웹 게임입니다. 빌드 과정 없이 `index.html`만 열면 바로 플레이할 수 있습니다.

## 📱 모바일 / 웹 바로 플레이
스마트폰이나 태블릿 브라우저에서 아래 링크로 접속하면 설치 없이 바로 플레이할 수 있습니다.
👉 **https://hcjo1223.github.io/Shisen-Sho/**

## 플레이 방법
- 같은 그림 두 개를 선택하면, 빈 칸을 통해 **꺾임 2번 이하**(직선 · L자 · U/Z자)로 이어질 때 사라집니다.
- 보드 바깥 테두리도 길로 쓸 수 있습니다.
- 더 이상 맞출 짝이 없으면 자동으로 섞입니다.
- 💡 힌트(`H`, 최대 5회) · 🔀 섞기(`S`, 최대 1회) · 시간제한 없음(소요 시간과 최고 기록만 저장)
- 🗓️ **오늘의 챌린지**: 날짜마다 정해진 판(보통 80개)을 모두가 똑같이 풀어요. 하루 최고 기록과 연속 일수가 남아요.
- 📤 클리어하면 **기록 카드 이미지**를 만들어 카카오톡 등으로 공유할 수 있어요 (공유 미지원 브라우저는 이미지 저장 + 문구 복사).
- 💾 진행 중인 판은 자동 저장돼요. 홈으로 나가거나 앱을 닫아도 홈 화면의 **이어하기**로 계속할 수 있어요.
- ⚙️ 게임 중 설정(난이도·테마·화면 모드·사운드)은 상단 톱니바퀴 버튼의 시트에서 바꿔요.

## 실행
```bash
npm ci
npm run dev      # 개발 서버
npm run build    # dist/ 빌드 + 저장소 루트로 동기화 (현재 Pages가 루트를 서빙)
```

## 오프라인 / 설치
- 홈 화면에 추가(PWA)할 수 있고, 한 번 열고 나면 서비스 워커가 게임 파일을 저장해 **오프라인에서도** 플레이할 수 있어요.
- 새 버전이 배포되면 다음 실행 때 자동으로 갱신돼요.

## CI / 배포
- `.github/workflows/ci.yml`: 모든 push·PR에서 테스트 → 타입 체크 → 빌드, 그리고 루트에 커밋된 빌드 산출물이 최신인지 확인해요.
- `.github/workflows/deploy.yml`: `main`에 push하면 `dist/`를 GitHub Pages로 배포해요. 저장소 **Settings → Pages → Source**를 **GitHub Actions**로 바꿔야 동작해요.

## 테스트
```bash
npm test   # tests/pathfinder.test.js + tests/daily.test.mjs
```
경로 탐색 결과를 "꺾이는 지점 후보 전수 조사" 정답 판정기와 무작위 보드 5,000쌍에서 대조합니다.

## 구조
| 파일 | 역할 |
| --- | --- |
| `js/pathfinder.js` | 2회 이하 꺾임 BFS 경로 탐색, 전체 짝 탐색 |
| `js/board.js` | 패딩 보드 생성, 셔플, 막힘 감지, 되돌리기 |
| `js/renderer.js` | 타일 DOM, SVG 연결선, 파티클 |
| `js/main.js` | 게임 상태 / 이벤트 / 기록 |
| `js/themes.js` | 이모지 테마 프리셋 |
| `js/sound.js` | Web Audio 효과음 (에셋 없음) |

## 참고
경로 탐색 알고리즘은 [engineer-myoa/Sichuan-HELPER](https://github.com/engineer-myoa/Sichuan-HELPER)의 `helper.py`를 참고했습니다.
- 계승: 숫자 맵(0 = 빈 칸) + 외곽 0 패딩, 꺾임 횟수를 추적하는 BFS와 2회 초과 가지치기, 보드 전체 스캔으로 연결 가능한 쌍 찾기
- 개선: 원본의 `close` 리스트는 한 번 지나간 칸을 영구 차단해서 더 적게 꺾이는 경로를 놓치는 경우가 있었고, 정사각형 맵(`VERTEX`)을 가정했습니다. 여기서는 직선 구간 단위로 BFS를 돌리고 칸마다 최소 구간 수를 기록해 이 문제를 고쳤고, 꺾임 횟수가 같으면 가장 짧은 경로를 고르며, 임의의 R×C 보드를 지원합니다.
