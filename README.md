# 🍓 말랑 사천성 (Emoji Shisen-Sho)

과일·동물 이모지로 즐기는 힐링 사천성 퍼즐 웹 게임입니다. 빌드 과정 없이 `index.html`만 열면 바로 플레이할 수 있습니다.

## 플레이 방법
- 같은 그림 두 개를 선택하면, 빈 칸을 통해 **꺾임 2번 이하**(직선 · L자 · U/Z자)로 이어질 때 사라집니다.
- 보드 바깥 테두리도 길로 쓸 수 있습니다.
- 더 이상 맞출 짝이 없으면 자동으로 섞입니다.
- 💡 힌트(`H`) · 🔀 섞기(`S`) · ↩️ 되돌리기(`Ctrl/⌘+Z`) · 시간제한 없음(소요 시간과 최고 기록만 저장)

## 실행
```bash
# 아무 정적 서버로 열면 됩니다 (또는 index.html 더블클릭)
python3 -m http.server 8080
```

## 테스트
```bash
node tests/pathfinder.test.js
```
경로 탐색 결과를 "꺾이는 지점 후보 전수 조사" 정답 판정기와 무작위 보드 5,000쌍에서 대조합니다.

## 구조
| 파일 | 역할 |
| --- | --- |
| `js/pathfinder.js` | 2회 이하 꺾임 BFS 경로 탐색, 전체 짝 탐색 |
| `js/board.js` | 패딩 보드 생성, 셔플, 막힘 감지, 되돌리기 |
| `js/renderer.js` | 타일 DOM, SVG 연결선, 파티클 |
| `js/main.js` | 게임 상태 / 이벤트 / 기록 |
| `js/themes.js` | 이모지 테마 프리셋 |
| `js/sound.js` | Web Audio 효과음 (에셋 없음) |

## 참고
경로 탐색 알고리즘은 [engineer-myoa/Sichuan-HELPER](https://github.com/engineer-myoa/Sichuan-HELPER)의 `helper.py`를 참고했습니다.
- 계승: 숫자 맵(0 = 빈 칸) + 외곽 0 패딩, 꺾임 횟수를 추적하는 BFS와 2회 초과 가지치기, 보드 전체 스캔으로 연결 가능한 쌍 찾기
- 개선: 원본의 `close` 리스트는 한 번 지나간 칸을 영구 차단해서 더 적게 꺾이는 경로를 놓치는 경우가 있었고, 정사각형 맵(`VERTEX`)을 가정했습니다. 여기서는 직선 구간 단위로 BFS를 돌리고 칸마다 최소 구간 수를 기록해 이 문제를 고쳤고, 꺾임 횟수가 같으면 가장 짧은 경로를 고르며, 임의의 R×C 보드를 지원합니다.
